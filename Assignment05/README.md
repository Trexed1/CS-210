# Assignment05

Tyler Rex's CS 210 implementations of array and linked stacks, queues, and deques.

Compile and run in the VS Code terminal:

```bash
clang++ -std=c++17 -Wall -Wextra main.cpp -o assignment05
./assignment05
```

- `main.cpp`: complete C++17 implementation and checked demonstrations.
- `CODE_GUIDE.md`: explanation of every class, the test driver, complexity, and compiler messages.
- `actual_output.txt`: captured output from the requested compile/run.
- `output/pdf/Rex_Tyler_Assignment05.pdf`: the single PDF for Canvas attachment.
- `Canvas_Post.md`: paste-ready initial discussion post with complete source code.

The initial Canvas post still needs the PDF attached in Canvas. Two substantive replies to different classmates require reading their actual posts.
