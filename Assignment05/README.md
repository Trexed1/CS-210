# Assignment05

Tyler Rex's CS 210 implementations of array and linked stacks, queues, and deques.

Build and run in the VS Code terminal:

```bash
clang++ -std=c++17 -Wall -Wextra main.cpp Stack.cpp Queue.cpp Deque.cpp -o assignment05
./assignment05
```

- `Assignment05.h` contains shared function declarations.
- `Stack.cpp`, `Queue.cpp`, and `Deque.cpp` each contain two implementations and their demonstrations.
- `main.cpp` is a short driver and prints checked results.
- `CODE_GUIDE.md` explains the code, testing, complexity, and compiler messages.
- `actual_output.txt` is the captured output.
- `output/pdf/Rex_Tyler_Assignment05.pdf` is the single PDF for Canvas attachment.
- `Canvas_Post.md` is the initial discussion post draft with every source file embedded.

The initial Canvas post still needs the PDF attached in Canvas. Two substantive replies to different classmates require reading their actual posts.
